How it works

A human signs every claim

Software assists; a person is accountable. Nothing goes to a payer without human review and sign-off — permanently, not just while the technology matures.

Your money never touches our hands

Payers remit directly to your clinic's accounts. We prepare, submit, and work the claims; the revenue path stays yours end to end.

Coded down, never up

The engine codes from what's documented — and only what's documented. When documentation is ambiguous, it selects the lower, defensible code and flags the gap for the physician instead of guessing upward.

No platform to install

We work from your existing EHR's exports and established clearinghouse rails. No new software for your staff, no migration project, no lock-in.

Don't take my word for it — check

Every page on this site loads from exactly one host: the one it is served from. No analytics, no tag manager, no web fonts, no CDN, no chat widget, no error reporter, no pixel of any kind. That isn't a policy I'm asking you to trust. It takes about a minute to confirm in your own browser:

  1. Press F12, open the Network tab, and reload this page. Every row's domain is this site's own.
  2. Stay there and use one of the tools — type an NPI, a date, a denial code. The request count does not move.
  3. Open Application → Storage. Cookies, Local Storage and Session Storage are all empty.
  4. View source and search for script src. There are no external scripts to find — every script here is inline, so there is nothing being pulled in from somewhere else.

And it stays that way by force rather than by good intentions: a test in the public repository loads every page in a real browser, records every request it makes, and fails the build if a single one leaves this origin, or if any page sets a cookie. You can read it — no-tracking.test.mjs — and yes, it contains the names of the trackers, because that is the list it hunts for.

Two honest limits. This site is hosted by GitHub, and like any web host it receives every request, including your IP address, whatever the page itself contains — the claim is that the page fetches from no one else, not that nobody sees the visit. And the scorecard request form opens your own mail application: the page transmits nothing, you send it yourself.
