    The group codes: CO, PR, OA and PI

    A remittance line carries two things: a claim adjustment group code that says who the money moves to, and a claim adjustment reason code (CARC) that says why. That is why staff write “CO-16” or “PR-1” — those are a pair, not a single code. X12 publishes exactly four group codes:

    CO — Contractual Obligation

    A contractual agreement between the payer and you, or a regulatory requirement, produced the adjustment. CMS describes these as generally a write-off for the provider and not billed to the patient — so treat it as a write-off unless the adjustment itself is wrong.

    PR — Patient Responsibility

    The adjustment is an amount that may be billed to the patient or insured. CMS says this group is typically used for deductible and copay adjustments; coinsurance (CARC 2) carries it too.

    OA — Other Adjustment

    CMS defines this as the group code used when no other group code applies. One concrete case is fixed by X12 itself: CARC 23, “The impact of prior payer(s) adjudication including payments and/or adjustments”, may be used only with group code OA — X12 says so in the code text itself.

    PI — Payor Initiated Reduction

    X12 publishes the name and no definition, and we found no published definition to quote — so we are not inventing one. What is verifiable: Medicare remittance advice does not use PI. CMS lists only CO, OA and PR as valid group codes for Medicare remittance advice.

    Group-code names above are verbatim from X12’s claim adjustment group codes list (retrieved 2026-07-29); the CARC 23 quote is verbatim X12. The CO, PR and OA descriptions follow the definitions in CMS Medicare Claims Processing Manual, Chapter 22, §60.1, which is Medicare-specific; other payers may apply the same group codes differently. The rest of the wording is ours.

    What to do first when denials cluster

    1. Separate real denials from adjustments before you count anything. CARC 1, 2 and 3 (deductible, coinsurance, copay) and CARC 45 (charge above the contracted allowed amount) are normal adjudication, not denials. Counting them makes a denial rate look far worse than it is. Leaving them out of the denial rate is not the same as writing them off: 1, 2 and 3 are patient money, not write-offs — they normally move to the patient rather than off your books. One federal exception matters in primary care: if the line carries Alert remark code N781, N782 or N783, the patient is a Qualified Medicare Beneficiary and federal law prohibits billing them for the deductible, coinsurance or copay — even though the line still reads PR with a dollar amount on it. Refund anything already collected. CARC 45 is the one that is genuinely not yours when the line carries group code CO; a PR-45 line may be billable to the patient, subject to your participation agreement and your state's balance-billing law. Check the group code and the remark codes on the line before you bill or adjust anything: the group code alone cannot tell you a QMB.
    2. Sort by dollars, not by count. A hundred $18 lines and four $600 lines are different problems with different fixes.
    3. Read the remark code on the same line. CARC 16 by itself never tells you what was missing — X12 requires at least one remark code with it, and that remark code is the actual answer.
    4. Ask whether it is a claim problem or a front-desk problem. Eligibility, prior authorization and timely filing denials are usually created before the claim is ever built. Reworking them one at a time treats the symptom.
    5. Check the payer’s own published policy before appealing. The X12 text is deliberately generic across every payer in the country. Whether a service needed authorization, how long you have to file, and what proof counts are all payer- and contract-specific.
    6. Accept that some denials are not recoverable. Timely-filing denials without proof of a timely original submission are a process fix, not an appeal, and a claim rejected as unprocessable (RARC MA130) carries no appeal rights at all — it has to be corrected and resubmitted as a new claim.

    Eleven codes worth understanding

    These eleven are written out because each one is handled differently from the others in a way that costs money if you get it wrong — not because we measured how often they occur. We found no published dataset of denial frequency, so this page carries no ranking, no percentages, and no claim about which codes turn up more often than others.

    CARC 16 — Something required was missing or wrong on the claim. The accompanying remark code says what.

    Official X12 text: “Claim/service lacks information or has submission/billing error(s). Usage: Do not use this code for claims attachment(s)/other documentation. At least one Remark Code must be provided (may be comprised of either the NCPDP Reject Reason Code, or Remittance Advice Remark Code that is not an ALERT.) Refer to the 835 Healthcare Policy Identification Segment (loop 2110 Service Payment Information REF), if present.”

    Typical next step: Read the RARC(s) on the same line — they name the missing element. Supply it and resubmit as a corrected claim.

    CARC 18 — The payer has already received this exact claim line.

    Official X12 text: “Exact duplicate claim/service (Use only with Group Code OA except where state workers' compensation regulations requires CO)”

    Typical next step: Check whether the original was paid before resubmitting. If it paid, post it and close. If it was a distinct second service the same day, an appropriate modifier may apply — only if the documentation supports two separate services.

    CARC 27 — The patient's coverage had already ended on the date of service.

    Official X12 text: “Expenses incurred after coverage terminated.”

    Typical next step: Re-verify eligibility for that date of service. If the patient moved to a new plan, rebill the correct payer. Front-desk eligibility checks at check-in prevent most of these.

    CARC 29 — The claim arrived after the payer's filing deadline.

    Official X12 text: “The time limit for filing has expired.”

    Typical next step: Check the payer's filing limit and whether you hold proof of timely original submission (clearinghouse acceptance report). If you do, submit that proof per the payer's process. If you do not, this is usually not recoverable — treat it as a process fix, not an appeal.

    CARC 45 — The charge was above the allowed amount. With group code CO this is a contractual write-off, not a denial; with group code PR the amount is patient responsibility — read the group code on the line.

    Official X12 text: “Charge exceeds fee schedule/maximum allowable or contracted/legislated fee arrangement. Usage: This adjustment amount cannot equal the total service or claim charge amount; and must not duplicate provider adjustment amounts (payments and contractual reductions) that have resulted from prior payer(s) adjudication. (Use only with Group Codes PR or CO depending upon liability)”

    Typical next step: If the line is CO-45, post the contractual adjustment. If it is PR-45, the amount may be billable to the patient, subject to your participation agreement and state balance-billing law — confirm before billing it. Either way, if the allowed amount looks wrong, compare it to your fee schedule with that payer before disputing.

    CARC 96 — The service is not a covered benefit. The accompanying remark code says why.

    Official X12 text: “Non-covered charge(s). At least one Remark Code must be provided (may be comprised of either the NCPDP Reject Reason Code, or Remittance Advice Remark Code that is not an ALERT.) Usage: Refer to the 835 Healthcare Policy Identification Segment (loop 2110 Service Payment Information REF), if present.”

    Typical next step: Read the RARC on the same line for the specific reason. Check whether the patient was given advance notice of non-coverage before billing them.

    CARC 97 — This service is bundled into another service already paid on the same day.

    Official X12 text: “The benefit for this service is included in the payment/allowance for another service/procedure that has already been adjudicated. Usage: Refer to the 835 Healthcare Policy Identification Segment (loop 2110 Service Payment Information REF), if present.”

    Typical next step: Verify the bundling against the payer's policy or the National Correct Coding Initiative edits. Only consider a modifier if the documentation genuinely shows a separate, distinct service.

    CARC 109 — This claim went to the wrong payer or contractor.

    Official X12 text: “Claim/service not covered by this payer/contractor. You must send the claim/service to the correct payer/contractor.”

    Typical next step: Re-verify the patient's active plan and the correct payer ID, then submit to the correct payer. Watch the new payer's filing deadline.

    CARC 197 — Prior authorization was required and was not obtained.

    Official X12 text: “Precertification/authorization/notification/pre-treatment absent.”

    Typical next step: Confirm whether the service actually required authorization for this plan. Some payers allow retroactive authorization in narrow circumstances — check the payer's published policy rather than assuming.

    CARC 204 — This item is not a covered benefit under the patient's plan.

    Official X12 text: “This service/equipment/drug is not covered under the patient's current benefit plan”

    Typical next step: Confirm the benefit with the payer. If the patient was informed in advance that it would not be covered, it may be billable to them under your financial policy.

    RARC MA130 — The claim was rejected as unprocessable, so there are no appeal rights — it must be corrected and sent again.

    Official X12 text: “Your claim contains incomplete and/or invalid information, and no appeal rights are afforded because the claim is unprocessable. Please submit a new claim with the complete/correct information.”

    Typical next step: Do not file an appeal; it will not be accepted. Read the paired reason/remark codes, fix the missing or invalid data, and submit a brand-new claim.
